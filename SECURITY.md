# Security

## Report a security problem

Do not open a public issue for a security problem.

Report it privately with
[GitHub private vulnerability reporting](https://github.com/simonsolts/routewell/security/advisories/new).
Only the maintainer can see the report.

Tell me:

- What the problem is
- How to reproduce it
- The Routewell version, macOS version, router model, and firmware version

## What to expect

Routewell is a personal project. I look at each report as soon as I can.

## Supported versions

Only the latest release gets fixes.
